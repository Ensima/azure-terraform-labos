# Plan de carrière : ingénieur cloud (sécurité) Azure jusqu'au freelance

Objectif : **démarrer en freelance vers 2031 comme « Ingénieur Cloud Azure – Sécurité »**, puis évoluer vers architecte cloud sécurité.

## Parcours

| Période | Étape | Certifications | Ce qu'il faut accumuler |
|---|---|---|---|
| 2026-27 | Alternance technicien (Numéritek) + Bac+3 | **AZ-104** | Bases Linux, réseau, Python (test d'admission Epitech) |
| 2027-29 | **Epitech MSc Cloud** + alternance ingénieur cloud dans un grand groupe (AXA, SG, VINCI, Generali…) | **SC-500** (sécurité cloud et IA, a remplacé l'AZ-500), Terraform Associate (optionnel) | Infra en code (Terraform), Azure Policy, gestion des identités (Entra ID), réseau privé (Private Link), pipelines CI/CD. **Réalisations chiffrées** et un **manager référent** |
| 2029-31 | CDI dans une ESN ou un cabinet spécialisé cloud (Avanade, Devoteam…) | **AZ-305** (architecte Azure expert), **SC-100** (architecte cybersécurité expert) | 2 ou 3 clients différents, au moins une mission de sécurité de référence |
| 2030-31 | — | **CISSP Associate**, certification IA d'ISC2 (lancement prévu en 2027) | Réseau : clients, managers, collègues freelances |
| **2031** | **Freelance** (portage salarial au départ, puis société) | — | Première mission signée avant de quitter l'ESN, 6 mois d'épargne |
| 2032+ | Freelance confirmé, puis architecte | Vrai **CISSP** une fois l'expérience atteinte | Tarifs de 600 à 700 € / jour et plus |

## Quel titre afficher en freelance

| Titre | Avantage | Inconvénient |
|---|---|---|
| Ingénieur Cloud Azure | Le plus de missions | Concurrence forte, tarifs moyens |
| Ingénieur Sécurité Cloud | Tarifs plus élevés, moins de concurrence | Moins de missions, les clients attendent de l'expérience en sécurité |
| **Ingénieur Cloud Azure – Sécurité / DevSecOps** ✅ | Apparaît dans les deux types de recherche | — |

## Les missions types visées

- Construction d'un **socle Azure sécurisé** : abonnements, groupes d'administration, Azure Policy, Terraform
- **Identités et accès** : Microsoft Entra ID, accès conditionnel, gestion des comptes à privilèges
- **Sécurité du réseau** : Private Link, pare-feu Azure, segmentation
- **Surveillance** : Defender for Cloud, Microsoft Sentinel
- **Mise en conformité** : ISO 27001, **DORA** (règlement européen sur la résilience numérique, applicable aux banques et assurances depuis janvier 2025),
  NIS2, SecNumCloud (cloud de confiance pour le secteur public)

**Atout à exploiter** : une alternance chez AXA ou SG, c'est une expérience dans la banque et l'assurance, où DORA crée une forte demande en sécurité cloud.

## Checklist « prêt pour le freelance » (à vérifier en 2031)

- [ ] Première mission signée avant la démission (ou la rupture conventionnelle)
- [ ] 6 mois d'épargne
- [ ] Contrat ESN vérifié : pas de clause de non-concurrence bloquante
- [ ] CV : « 4 ans d'expérience en ingénierie cloud, dont 2 en alternance », avec des réalisations chiffrées
- [ ] 2 ou 3 personnes prêtes à te recommander
- [ ] Profils Malt et Free-Work à jour, dépôt GitHub propre
- [ ] Statut choisi : portage salarial pour démarrer

Ce qui le fait vraiment monter : **des missions en direct** et **des références en sécurité**.

| Pays | Repère freelance cloud / Azure | Remarques |
|---|---|---|
| France (Île-de-France) | 450-550 € / jour en junior via intermédiaire, 600-725 € confirmé | Référence |

| Pays-Bas | Moyenne de tous les freelances ≈ 83 € / heure (pas propre au cloud) | Anglais suffisant |
| Suède | Une mission Azure sécurité à 650-700 € / jour | Une seule annonce |
| Luxembourg | Pas de données fiables trouvées | Secteur financier, possibilité d'être frontalier |

**Conclusion** : seule la **Suisse** paie nettement plus. Ailleurs, un freelance confirmé est payé à peu près comme en France.
Le meilleur moment pour partir est **une fois confirmé (vers 2031-2033)**, avec un anglais de niveau C1 (et de l'allemand pour Zurich).
